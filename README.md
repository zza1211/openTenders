## 范围与验证

- 原始 PDF 保持发布源文件内容，未重排或改写。全部可打开、未加密、可提取英文正文；每个项目核验具体技术条款并渲染代表技术页。
- 按独立项目和文件 SHA-256 双重去重；同一项目的公告、补遗、附件不单独累计。技术附件或更正合规表本身可作为该项目的样本。
- 历史文件用于技术条款和标书结构参考；不表示项目仍在招标。若用于实际投标，须回到来源确认补遗、版本和有效期。
- 大多数文件具有数值、端口、速率、协议或光学参数。BOM 型以型号、数量和许可证为主；项目方案型以集成、迁移、功能、验收和服务要求为主。
- 本页的结构分类为本次整理标签；具体结构特点见逐篇说明。技术页码为从 1 开始的 PDF 物理页序，不一定等于文件印刷页码。
