# ICT English Tenders - Batch 2

This is a standalone second collection of 50 English ICT networking procurement documents. It is kept separate from `ICT_English_Tenders_50` and has no SHA-256 duplicate from Batch 1.

## Coverage

- Documents: 50
- Total PDF pages: 4150
- Product areas: switches, routers, firewalls, SD-WAN, VPN, optical transceivers, SFP/SFP+/QSFP, GPON/XGS-PON OLT, ONU/ONT, ADC/load balancers, NAC, packet brokers and network management
- Document forms: full tenders, technical annexes, compliance matrices, corrigenda, municipal schedules, service RFPs, BOQs, GeM documents, two-envelope bids and telecom generic requirements

## Contents

Every item includes the source PDF, page-level extracted text, a first-page PNG preview, source URL, SHA-256 and automatically identified technical pages in `catalog.json`. Image-only pages are preserved in the original PDF and marked in the extracted text.

Open `index.html` locally for searchable filters by product, country, year, document form and technical category.

## Validation

`validation_report.json` records the final count, page count, category distribution, unique hashes and the first-batch duplicate check.
