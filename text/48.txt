       Technical Specification for GPON- ONU/ONT with Wifi support
                                 Qty: 260 Nos.

1. Make & Mode: To be specified by the bidder

2. PON interface (Minimum Requirement):
   • 1 XPON port
   (EPON PX20+ and GPON Class B+)
   • SC Single mode
   • TX optical Power: 0 to 4 dBm
   • Transmission distance: 20 km
   • RX: 2.488 Gbps, TX: 1.2488 Gbps

3. LAN interface (Minimum Requirement):
   • 2 * 10/100/1000 Mbps auto adaptive Ethernet interface, RJ45 connectors, 1 POTS Rj11
  Connector
4. Wavelength (Minimum Requirement):
  Transmission wavelength: 1310 nm
  Receiver wavelength: 1490 nm
 TX optical Power: 0 to 4 dBm
5. Sensitivity/Optical type:
  Receiver Sensitivity: should be -8dBm to -25dBm
  Optical Type: SC/PC
6. Wireless:
   Should be Compliant with IEEE 802.11 b/g/n/ac
7. Indicators (Minimum Requirement):
  Power, LOS, PON, LAN2, LAN1, TEL, 2.4G, 5G, Phone
8. VLAN - Should
  Support VLAN tag mode
  Support VLAN translation mode
  Support VLAN trunk mode
9. Multicast - Should
  Support IGMP v1/v2/v3
  Support IGMP Proxy and MLD Proxy
  Support IGMP Snooping and MLD Proxy Snooping
10. QoS - Should
  Support 4 Queues
  Support SP and WRR
  Support 802.1P
  Support DSCP

   Support DMZ
   Support DHCP Server
